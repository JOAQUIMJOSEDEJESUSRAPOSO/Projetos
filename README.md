# Pedra, Papel e Tesoura

Jogo de Pedra, Papel e Tesoura desenvolvido em Python utilizando Tkinter para a interface gráfica.

## Funcionalidades

- Escolha entre Pedra, Papel ou Tesoura
- Jogadas aleatórias do computador
- Contador de vitórias, derrotas e empates
- Interface gráfica simples e intuitiva

## Tecnologias Utilizadas

- Python
- Tkinter
- Random
